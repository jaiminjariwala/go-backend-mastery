What do these results mean?

Cache hit: Redis supplied the destination. Cache miss: Redis had no mapping, so Go asked PostgreSQL and tried to save the result for 60 seconds. Cache error: Redis failed, so Go tried PostgreSQL. Baseline: the cache was intentionally skipped. A 429 means the client used its rate allowance; Retry-After tells it when to try again. A 503 can mean the shared rate limiter is unavailable.
