# Go Backend Mastery

My personal learning repository for backend engineering and distributed systems in Go.

I'm learning one concept at a time through small, working examples, writing code myself, and keeping notes that explain the syntax and reasoning. The focus is on understanding the basics before moving to more advanced topics, not following a fixed daily schedule.

The earlier numbered folders contain my Go exercises. My current learning continues in `14-backend-labs`, with concept-specific explanations, commented code, and tests. Topics will gradually include APIs, databases, caching, rate limiting, message queues, concurrency, and distributed systems. Visual demos will be added where they help explain a concept.

This repository is a work in progress and reflects what I'm learning along the way.
