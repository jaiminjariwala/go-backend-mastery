# Shared learning website (planned)

This folder reserves the location for one shared UI, not a separate website per lesson.

The first screen will send requests to the HTTP lesson and display the actual status, headers, body, and elapsed time. Later concepts will get their own routes in the same app.

Keep the UI minimal: concept sidebar, explanation and experiment area, optional details panel. Use restrained light surfaces, thin borders, and blue actions inspired by the existing projects. No frontend dependencies or UI code have been added yet.
