Lesson 06 · Middleware

“Stop preparing my order”

You order food. The kitchen starts preparing it. If you cancel, the waiter tells the kitchen to stop. A request's context carries that stop signal; the work must listen to it.

Start a task
     │
     ▼
Server waits for whichever happens first:
     │
     ├── Work finishes → return a successful reply
     ├── Deadline arrives → stop work and return a timeout reply
     └── You cancel → browser stops waiting;
         server detects cancellation and stops work
Choose a task.

After canceling, check the Go terminal for “client canceled; task stopped early”. The browser cannot receive confirmation on a request it has aborted. These tasks are real interruptible waits, not database writes. Graceful shutdown is implemented too: start the 10-second task, then press Control+C in the Go terminal without canceling the browser request. The server stops accepting new connections and allows up to 12 seconds for active requests to finish. Restart Go afterward.
